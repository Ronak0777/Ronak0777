## 🚀 Featured Projects

### 🍽️ [Nivedanam — Restaurant Management System](https://github.com/Ronak0777)
Desktop-based restaurant management system built with **Java, JavaFX, JDBC & MySQL**.
- Secure login authentication & multi-screen dashboard navigation
- Billing and invoice generation via Java file handling
- CRUD operations for menu management
- Modular, OOP-driven architecture

### 🔥 [Fire Safety Training VR Simulation](https://github.com/Ronak0777)
Immersive VR fire safety training built with **Unity 3D & C#**, optimized for Meta Quest 3.
- Realistic fire emergency scenarios: outbreaks, smoke spread, evacuation routes, hazard detection
- Spatial audio, 3D modeling, and immersive UI/UX
- Tested and optimized for smooth VR performance

### 🌾 [Kisan AI](https://github.com/Ronak0777)
Responsive **React.js** web app supporting farmers with AI-based crop disease analysis.
- Image upload flow for crop health diagnostics with proposed solutions
- Fertilizer tracking & agri-market updates
- Integrated chatbot for farmer queries and app guidance

### 🪙 [Criptify — Crypto-Enabled Digital Platform](https://github.com/Ronak0777)
Scalable web/mobile platform for cryptocurrency-based transaction tracking.
- Containerized deployment with **Docker** for scalability and reliability
- Real-time data handling with a responsive UI
